# O(log n) - Logarithmic Examples

This project demonstrates algorithms with **O(log n)** complexity.

## What is O(log n)?

The execution time increases by **1 unit** when the input doubles (not double).

- Doubling the input = +1 to execution time
- Binary Search in a sorted array is the classic example

## Examples Included

1. **Binary Search (Iterative)** - Searches a sorted array by repeatedly dividing the search interval in half
2. **Binary Search (Recursive)** - Same algorithm implemented recursively
